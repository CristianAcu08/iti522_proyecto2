Arquitectura de la Solución de Inventario

Arquitectura híbrida PaaS/IaaS implementada en Microsoft Azure con respaldo continuo y alta disponibilidad

Capa de Presentación y Móvil

  • • Despliegue en Azure Static Web Apps con SSL global automático.
  • • Diseño responsivo para transportistas en ruta desde smartphones.
  • • Interfaz moderna con estilos Glassmorphism y validación cliente.

Capa de Lógica y Procesamiento

  • • Azure App Service Linux ejecutando Node.js / Express.
  • • Endpoints CRUD: /api/articulos (GET, POST, PUT, DELETE).
  • • Endpoint de monitoreo de salud: /health.

Capa de Datos y DRP (Continuidad)

  • • PostgreSQL 16 en VM Ubuntu (Cumplimiento de restricción legal).
  • • Respaldo diario automático (Cron 02:00 AM) hacia Blob Storage.
  • • RPO: 24 horas | RTO: 45 minutos | Procedimiento de restore validado.
